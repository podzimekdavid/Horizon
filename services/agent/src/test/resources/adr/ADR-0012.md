# ADR-0012: Payments stay in the payments module

Status: proposed

## Context

Checkout started importing the payments SDK directly.

## Decision

Payments code lives under src/payments. Other modules do not import the payments SDK.

## Rejected alternatives

- A shared billing helper under src/common.
- Calling the provider SDK from checkout.

## Consequences

Checkout depends on the payments module.

## Governs

`src/payments/**`, `src/checkout/**`
